# fmllm.physics

LJ Hamiltonian, MD integrator, and physical observables.

Phase 1 will add:
- `lj_potential.py` - Lennard-Jones pair potential plus harmonic
  confinement, returning energy and forces.
- `md.py` - vectorized velocity-Verlet integrator for 2D MD.
- `structures.py` - generators for canonical 2D cluster motifs.
- `observables.py` - radial distribution function, kinetic-energy
  distribution, and the position-to-image rasterizer.

Currently empty.
