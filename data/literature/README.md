# data/literature/

Curated reference dataset the verifier's `LiteratureSource` consults.

## Files

- `clusters.json` - per-(N, motif) reference records: per-atom
  potential energy at zero temperature under the project's LJ
  Hamiltonian, first-peak position of the pair-distance histogram,
  cluster diameter, and a citation string. Generated by
  `scripts/build_literature_db.py` from canonical structures.

## Schema

Each entry:

```json
{
  "n_atoms": 7,
  "motif": "triangular_disk",
  "per_atom_potential_energy_lj": -1.79,
  "rdf_first_peak_lj": 1.13,
  "diameter_lj": 2.24,
  "reference": "computed from fmllm.physics with sigma=epsilon=1, ..."
}
```

The verifier reads this file at startup and uses it for
literature-source agreement checks against FM2's per-atom energy
predictions and FM1's count head.

## Updating

Re-run `uv run python scripts/build_literature_db.py` whenever the
canonical structure generators change. The script writes
`clusters.json` deterministically; the diff should be empty unless
someone changed the LJ Hamiltonian or the structure generators.
