# docs/audits/

One self-audit report per phase. Each report runs the audit checklist
from the original prompt against the actual repo state, marks each
check pass / fail / fixed, and signs off only when every check passes.

## Files

- `00-init-audit.md` - Phase 0 audit.
- `01-testbed-audit.md` - Phase 1 audit.
- `02-fms-audit.md` - Phase 2 audit.
- `02-fms-retrofit-audit.md` - Phase 2.5 retrofit audit (addendum).
- `03-bridges-audit.md` - Phase 3 audit.
- `04-verifier-audit.md` - Phase 4 audit.
- `05-orchestration-audit.md` - Phase 5 audit.

Subsequent phases add one audit report each.
