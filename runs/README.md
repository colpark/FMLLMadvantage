# runs/

Run artifacts. Every script that produces output writes under
`runs/<run_id>/`, where `<run_id>` follows the
`YYYYMMDD-HHMMSS-<slug>` format generated by
`fmllm.utils.run_ids.generate_run_id`.

The directory is gitignored except for this README. Run output stays
on the remote machine. Send specific artifacts back through the
appropriate review channel rather than committing them.

A typical run directory contains:
- `run.log` - per-run loguru file sink at DEBUG and above.
- `manifest.yaml` - manifest written by `fmllm.utils.manifests.write_manifest`.
- Per-stage outputs (checkpoints, predictions, plots).
